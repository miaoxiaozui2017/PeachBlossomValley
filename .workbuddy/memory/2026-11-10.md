## 经验（Unity 运行时生成 UI 的坑）
- 绝不要缓存 `new GameObject(...).transform` 后再给它加 `RectTransform`；应始终用 GameObject 变量，`AddComponent` 完成后再取 `.transform`。
- 运行时生成 UI 对象时，一个 GameObject 只能有一个 Transform/RectTransform，重复 AddComponent 返回 null。
- uGUI Text 创建后必须显式赋 `.text`；漏赋值表现为「有底板无文字」，容易被误判为渲染/相机问题。
- 成就/统计类判断不要用「集合非空」，要先确认集合里的元素是否真的达到目标状态（很多系统会提前创建占位对象）。
- `ItemType` 枚举顺序：0=Resource, 1=Tool, 2=Consumable, 3=Seed（资产 .asset 里 type 用数字）。
- 物品资产脚本 GUID 固定 `d7e0e37fc99f0264581c6e1adcf1bce8`；新建 .asset 时注意 `m_Enabled: 1` 冒号后必须有空格。
