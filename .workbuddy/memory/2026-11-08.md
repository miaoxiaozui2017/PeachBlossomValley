
## 上午 UI 交互重大 bug 修复（用户报：提示遮挡 + 造纸台按钮点不动）
根因1（按钮完全点不动）：场景里从未创建 EventSystem（SceneBuilder 没有，场景文件 grep=0）。
  → 所有 uGUI Button 收不到点击。修：新建 UI/UIEventSystemBootstrap.cs，
    HUD.Awake 与 InteractionPromptUI.Awake 调 Ensure()，运行时自动补 EventSystem+StandaloneInputModule。
    activeInputHandler=2(Both)，旧输入可用。幂等，无需重建场景。
根因2（遮挡+吃点击）：7 个面板(HelpUI/BuildUI/CraftingUI/CookingUI/MineUI/ShopUI/ToolUpgradeUI)
  的全屏半透明 BG 挂在 canvasGo 下，不受 _root.SetActive 控制 → 常驻叠加在最上层、
  raycastTarget=true 吃掉所有点击。修：加 _canvasGo 字段，BuildUI 赋值，
  所有 _root.SetActive → _canvasGo.SetActive（整块 Canvas 一起开关）。
  同时 QuestLogUI/SkillPanelUI 统一改。
根因3（视觉层级）：HUD sortingOrder 40、交互提示 55、背包 50 都高于功能面板 23~30。
  修：HUD→5 且移除 GraphicRaycaster、所有 Text/Image 关 raycastTarget；
  交互提示→10 同理；背包→15 且 hotbar 底板关 raycastTarget；
  HUD 底部操作条移到左下角，避开中央 [E] 交互提示。
根因4（材料够但按钮灰）：CraftingSystem/CookingSystem/FishingSystem/MineSystem/ToolManager
  用 Resources.FindObjectsOfTypeAll<ItemData>() 只返回已加载对象 → 材料资产引用为 null
  → CanCraft 恒 false。修：全部改 Resources.LoadAll<ItemData>("Data")；
  CraftingSystem 解析失败不锁 _resolved；CraftingUI.Refresh 主动重试解析。
兼容：Ensure() 里禁用并销毁旧场景残留的 IntroSystem（全屏黑底）、
  自动补挂 HelpUI 组件 → 不重建场景也能用 H 帮助页。

  改用 _CompileCheck 项目副本（只复制 Scripts/Editor/ProjectSettings/Packages）编译验证。

## 23:15 第三批试玩反馈（15 条）统一处理
关键设计约定（今后沿用）：
- **输入**：农事工具 = 鼠标左键（点在 UI 上用 EventSystem.IsPointerOverGameObject 过滤），
  Space 专供钓鱼 QTE；钓鱼期间 FishingSpot.IsFishingActive 禁用左键农事。
  成熟作物左键直接收（按镰刀体力计），不必切镰刀、不用再浇水。
  E = 交互 / 关面板；F = 吃选中料理；L = 成就面板。
- **UI 栈顶**：UIEventSystemBootstrap 加 RegisterTopPanel/UnregisterTopPanel/
  TryCloseTopPanel/ClearTopPanel；InputHandler 在 E 按下时先关栈顶面板再决定是否交互，
  避免「E 关掉又被同一次 E 重新打开」。8 个功能面板已接入。
- **料理**：不再做完直接回体力，改为产出菜品进背包，可按 F 吃 / 送礼 / 出售。
  ItemData 新增 staminaRestore 字段；13 个 item_dish_* 资产已直接写入 Assets/Resources/Data
  （含 .meta，Unity 自动导入，不重建场景也能用）；CookingSystem 支持通配材料 "any_fish"，
  加了 3 道鱼料理；SaveManager.FindItem 增加 Resources.LoadAll 兜底，保证读档不丢新物品。
- **出售**：规则集中在 ShippingBinSystem.CanSell（售价>0 且非 Tool/Seed）。
  商店新增「回收背包物品」按基础价即时到账，不享现代×2 / 节日×1.5；
  出货箱仍是高价渠道，倍率在投入那一刻锁定、次日 06:00 入账。
- **背包扩容可见**：InventoryUI 预建 48 格但按 Capacity 显示/隐藏，标题显示 24/36/48，
  面板高度随行数变化；Update 轮询容量兜底（ExpandCapacity 不一定发变更事件）。
- **雨天**：WeatherSystem 加 [DefaultExecutionOrder(-100)] 先定天气，移除其 AutoWaterAll；
  CropManager.OnNewDay 用「isWateredToday || 雨天」推进生长 → ResetWaterState →
  AutoWaterAll(false) 只留湿润视觉，不产生次日免费生长。
- **睡觉 vs N**：TimeManager.ForceNextDay(bool fromBed) + LastAdvanceWasSleep；
  PlayerStats.OnNewDay 睡觉回满、N 只回一半；Bed 不再自己 RestoreFull。
- **提示**：HUD.ShowNotice 接入制作/烹饪缺材料、工具升级缺矿/钱、扩建、购买、回收、
  送礼、出货、成就解锁；灰色按钮改为常可点，由系统层弹具体原因。
- **工具消耗显示**：ToolManager.TryUpgrade 成功后触发 OnToolChanged；HUD.Update 再加字符串轮询兜底。
