# 2026-11-11 工作日志

## 商店买卖双渠道（提交 8ba09fb，已推 github/main）
用户需求原话：「商店可以买卖（商店有时间限制，且价格和商人好感度有关，可以便宜买，高价卖），当场结算，（商店关门后还需出货）次日卖出走出货箱」。

**设计结论：两条卖货渠道互补，别混**
| | 商店（当场结算） | 出货箱（次日 06:00） |
|---|---|---|
| 时间 | 06:00-18:00 营业 | 全天 |
| 价格 | 基础价 ×(1+好感溢价)，**不乘**现代×2/节日×1.5 | 可乘倍率，投入瞬间锁定 |
| 定位 | 急用钱、白天顺手卖 | 高价渠道、批量、打烊后唯一出路 |

**实现要点**
- `ShopSystem`：新增 `_openHour=6` / `_closeHour=18`、`IsOpenNow`、`CanTrade`；`BuyMultiplier=1-0.2×好感/100`（挚友 8 折）、`SellMultiplier=1+0.3×好感/100`（挚友 +30%）；`GetBuyPrice` / `GetSellUnitPrice`（含今日事件「货商过境」+20%）；`TrySell` / `TrySellAll(out count,out money)` 当场结算并各自弹一条汇总提示；`GiftToMerchant()`。
- **商人身份**：商店是「NPC 融合进建筑」，物体上没有 NPCController，所以 `MerchantName` 按 `gameObject.name` 推断：杂货铺=「商人」、TavernStation=「饱饱（酒楼大厨）」、FarmVendorStation=「老农」（与已有 NPC 好感共用 key）。`PlayerController.OnGiftInput` 增加 `else if (CurrentNearby is ShopSystem shop) shop.GiftToMerchant()`，否则 G 送礼送不到商人、好感永远 0。
- `ShopUI` 重写：上半「购买」（折后价 + 划线原价）、下半「出售」（逐件 卖1/全卖）+ 一键全部卖出；状态栏常驻营业状态(绿/红)、好感等级、买折扣、卖溢价；打烊时所有按钮 `interactable=false` 并变灰，`Update` 检测 `CanTrade` 跨小时变化自动刷新；暴露 `RefreshIfOpen()` 供送礼后即时刷新。
- `TimeManager.SkipToHour(20)` + `Shift+N`（不换日、不结算）→ 明早可一键测「打烊 → 投出货箱 → N 结算」。原 N 跳日回 06:00 永远营业，测不到打烊。
- 文档：HelpUI 第 5/6/15 条与快捷键表、试玩指南循环一加双渠道对照表、归档清单追加 241-250 验收项。

## 古今商店隔离 + 全物品定价（提交 ac2a9f2，已推 github/main）
用户三处拍板（AskUserQuestion）：**古玩店卖文物收藏品 / 复用 Tab 背包面板 / 切世界整店隐藏**。
需求原话：「穿越到现代只有一家杂货铺，和一家古玩店，穿越回桃花谷保留现在已有的，商店古今不通用（在美术上和可买卖物品上会有区别），两边的商店只写可买的东西，背包里一切物品可售卖，直接给物品定价即可，鼠标选中背包后，可在和商城交易打开背包界面里看到物品价格」。

| 世界 | 店铺 | 币种/美术 | 货架 |
|---|---|---|---|
| 桃花谷 | 杂货铺/酒楼/老农小摊（保留） | 文 · 暖色 | 种子/食材/堆肥/工具/招牌菜 |
| 现代 | 现代杂货铺 ¥冷蓝 / 古玩店 ¥金铜（新建） | ¥ · 冷蓝/金铜 | 现代资源/复合肥/图纸/工具；文物收藏品 |

**实现要点**
- 新增 `ShopWorldBootstrap.cs`（已补 csproj Compile + .meta）：运行时补建现代两家店、`Resources.FindObjectsOfTypeAll<ShopSystem>()` 按 `ShopWorld` 显隐（含隐藏对象）、`OnWorldChanged` + 0.5s 低频兜底；`ShopSystem.Start` 自我对齐，覆盖「补建晚于事件」时序。
- `ShopSystem` 重构：加 `ShopWorld` 枚举与 `_world`；删掉「同一物体按世界切 `_items`/`_modernItems`」逻辑 → 每店单一独立货架；`IsRMBShop` 决定收付币种；`AddModernEntry` 保留为兼容包装。
- **古今商店不通用**：ContentExpansion 里 `FindObjectOfType<ShopSystem>()` 改为按物体名 `NPC_ShopKeeper` 精确查找（现代店可能先创建），且用 `FindObjectsOfTypeAll` 兼容读档直接进现代时该店已隐藏。现代货架从桃花谷店剥离，改由 ShopWorldBootstrap 自己上架。
- **全物品可售**：36 个 0 价资产批量补定价（菜品45/药35/工具60/图纸15/现代资源8-12/茶饮25），172 个 ItemData 全部 `sellPrice>0`；`ShippingBinSystem.CanSell` 简化为 `item != null && sellPrice > 0`，删掉 Tool/Seed 类型限制与无用 `_sellSeeds`。图纸买价 30-40 卖价 15，防套利。
- **工具可买回**：既然工具能卖，两家杂货铺都上架四件工具（买 90 / 卖 60），否则玩家卖光工具会卡死。
- **商店面板只列可买的东西**：ShopUI 移除出售区，改为「卖选中 ×1 / 卖选中整叠 / 全部卖出」按钮，读 `InventoryUI.SelectedSlotIndex`；`ShopUI.CurrentShop` 静态供背包信息栏读取实收价。Tab 背包信息栏常驻显示「基础售价 N」+ 商店打开时「卖给XX N/件（含好感）」。
- **两个面板能同时点**：商店面板 `anchoredPosition=(-360,0)`、Canvas `sortingOrder=14`（低于背包 15）、全屏 BG `raycastTarget=false`。否则 30 层的全屏 BG 会抢走背包格子的射线。
- 美术区分：`EnsureLabel` 加可选 `textColor`，现代店冷蓝字、古玩店金铜字；色块颜色也不同。现代店放第 1 排右端 (16,9)/(20,9)，传送后最显眼。
- 文档：HelpUI 4/5/6 条、试玩指南循环一（双渠道表 + 古今商店表）与循环五、已知限制、归档清单 251-260 验收项。

## 约定 / 经验
- 商店与出货箱**故意保持不同倍率**：商店当场结算的便利不能同时吃高价，否则出货箱失去存在意义。
- 好感定价用连续系数（非阶梯），状态栏显示 `X.X 折 / +N%`，玩家可直接看到送礼的收益。
- 新增 MonoBehaviour 的 SerializeField 在旧场景里会走代码默认值，无需重建场景；删掉的 `_modernItems` 字段在旧场景序列化里会被 Unity 忽略，安全。
- **uGUI 多面板共存**：全屏 BG 必须 `raycastTarget=false`，且 BG 所在 Canvas 的 sortingOrder 要低于另一个可点面板，否则射线被抢；面板位置左右错开。
- **运行时补建 + 世界显隐**要三重保险：创建时自我对齐、事件刷新、低频兜底轮询；查找隐藏对象必须用 `Resources.FindObjectsOfTypeAll`，`GameObject.Find`/`FindObjectOfType` 找不到 inactive。
- 用户偏好：结论先行、简洁、能用表格就用表格；文档按「可玩循环」组织，不堆逐条清单；需求含架构分叉时先用 AskUserQuestion 拍板再实现。
