《谷中仙》完整游戏设计文档

1. 核心概念

996程序员梦中穿越到古代桃花谷，经营农场、体验田园生活、修复古画，在现实与梦境间做出选择。

1.1 开场动画设计

形式：2D手绘风格动画（类似《星露谷》开场）+ 动态像素过渡

时长：约60-90秒

结构：现代压抑 → 穿越奇景 → 古代新生

配乐：从压抑的电子环境音，渐变为空灵的古琴/箫声，最后转入温馨的田园主题。

详细分镜：

1. 【现代，夜，办公室内】 (0-15秒)
	◦	画面：俯视镜头。一个像素小人（主角）僵坐在格子间电脑前，屏幕蓝光映着疲惫的脸。周围是漆黑一片，只有他头顶一盏惨白的灯。窗外是都市霓虹和冰冷的雨。
	◦	文字：“这是我连续加班的第37天。”
	◦	音效：键盘敲击声、雨声、隐约耳鸣。

2. 【崩溃与遗物】 (16-30秒)
	◦	画面：主角用力合上电脑，将脸埋在手中。他打开抽屉，拿出一个古朴的木匣——这是爷爷唯一的遗物。他颤抖着打开，里面是一卷残破的古画，画上依稀可见桃花与远山。
	◦	文字：“爷爷说，如果累了，就看看这幅画……”
	◦	音效：心跳声加重，打开木匣的“吱呀”声。

3. 【穿越奇点】 (31-45秒)
	◦	画面：当他的手指触碰到古画破损处的瞬间，画卷突然发出柔和的金色光芒。办公室的景象如潮水般褪色、瓦解。像素画面开始剧烈波动、色块分离。
	◦	文字：“它……在呼吸？”
	◦	音效：所有现实音效骤然停止，变成空灵的蜂鸣和风声。音乐起。

4. 【坠入梦境】 (46-60秒)
	◦	画面：主角被吸入画中。镜头高速穿梭过水墨风格的星空与流云。下方，一片被薄雾笼罩的桃花谷逐渐清晰。画面风格从写实像素，彻底变为游戏内的青绿山水像素风格。
	◦	文字：（无文字，纯视觉享受）
	◦	音效/音乐：风声呼啸，音乐转为悠扬、充满希望的主旋律。

5. 【古代新生】 (61-75秒)
	◦	画面：主角轻飘飘地落在谷中一片桃花林里。他睁开眼，看到的是漫天花雨、清澈溪流、远处古朴的村舍。一只像素蝴蝶落在他肩头。他身上的现代服装，像素逐渐重组，变成了粗布古装。
	◦	文字：“……这里是？”
	◦	音效：鸟鸣、流水、花瓣飘落的细微声响。

6. 【第一缕光与抉择】 (76-90秒)
	◦	画面：朝阳初升，第一缕阳光刺破山谷的晨雾，照亮他面前一条通向村庄的石板小径，也照亮了小径尽头一座破旧但可辨认的茅屋（他的起点）。镜头拉远，展现桃花谷全貌的美丽与宁静。
	◦	文字：“谷中仙”
	◦	音效/音乐：音乐达到最辉煌的段落，然后缓缓收尾，融入游戏标题界面的BGM。

2. 游戏系统

2.1 核心世界观

• 设定：现代程序员深夜加班睡着，意识坠入家传古画《桃花源图》

• 目标：经营古画中的桃花谷，修复逐渐褪色的古画，解锁更多区域

• 选择：最终在"留下"与"回归"间做出抉择，影响结局

2.2 种植系统

• 基础循环：开垦 → 播种 → 浇水 → 施肥 → 收获

• 作物系统：

  ◦ 20+种作物，分属四季

  ◦ 生长阶段：种子→幼苗→成长期→成熟期

  ◦ 影响因素：季节、天气、土壤肥力、节气效果

• 农耕进阶：

  ◦ 土地类型：荒地 → 旱田 → 水田 → 梯田

  ◦ 农具升级：石制 → 青铜 → 铁制 → 精钢

  ◦ 水利系统：可建造水渠实现自动灌溉

2.5 NPC社交系统深度化

设计原则：每个NPC都有独立的“日程表”、“人际关系网”和“秘密”。

社交与攻略系统：

• 可攻略角色：设计4男4女共8位角色，涵盖不同性格与背景（如落魄画师、归隐太医、外冷内热的镖师等）。

	• 书斋先生：白天教书，傍晚河边独酌，实则怀念逝去的爱人（其故事与“制墨”非遗线深度绑定）。

	• 铁匠娘子：表面爽朗，暗地偷偷练习剑法，梦想成为侠女（赠送剑谱可极大提升好感）。

	• 神秘道士：云游四方，出售稀有种子，真实身份是古画的“守卷人”。

• 好感度等级：冷淡 → 相识 → 友好 → 知己 → 倾心。达到“倾心”可触发专属剧情线。每人5个心事件 + 3个分支选择


• 情感抉择：NPC间有独立关系网，影响玩家社交。与一位角色关系过密，可能引起其他相关NPC的微妙反应（如兄弟反目、姐妹嫉妒）。

• 结局分支：根据玩家选择、古画修复进度、攻略角色关系，可达成 “回归现代”、“永驻桃源”、“携美同归” 等多重结局。

• "面子"系统：宗族声望影响交易价格、任务触发

• 社区任务：修复“年久失修”的社区建筑（如茶馆、祠堂），解锁新功能，推进主线剧情。

2.6 现实世界系统

定位：游戏进程的调节器、叙事反转的催化剂，与现实形成资源互补循环。

玩法模块：

1. 现实经营：经营现代“古风文创店”，售卖桃花谷的非遗制品维持生计。

2. 知识转化：将现实“现代知识”（化学、机械等）转化为桃花谷的“特殊道具/图纸”。

3. 情感羁绊：现实人际关系（家人/朋友）影响玩家的“心理状态”，进而影响游戏内的“精力值”恢复。

4. 时空穿梭：通过“修复古画”或“特定节气”消耗资源触发穿梭，连接两界。

玩法循环：现实世界（赚钱、学习） → 穿梭 → 桃花谷（制作、探索） → 带回现实（售卖、升级） → 现实世界。
 ◦ 2.6.1 现代营生系统：详细定义汉服设计师、水墨画家、古玩店老板、中医四种职业。

    ▪ 解锁条件：与古代对应的非遗精通度、NPC好感度、完成特定任务。

    ▪ 核心玩法：每种职业有独特的“现代手作”玩法、客户系统、升级路线。

    ▪ 经济联动：古代产原料/半成品 → 现代加工为高附加值商品 → 现代售卖/完成任务。

  ◦ 2.6.2 穿梭贸易规则：

    ▪ “三出三进”原则：每次穿梭，玩家可从古代携带至多三样物品到现代，反之亦然。

    ▪ 策略核心：物品有“时代溢价”。携带现代药品到古代是“神药”，携带古代真迹到现代是“国宝”。选择直接影响两边发展速度。

    ▪ 冷却与限制：穿梭有冷却时间，或需消耗特殊资源（如“梦境能量”）。

  ◦ 2.6.3 钓鱼系统：

    ▪ 古代钓鱼：在桃花谷的溪、河、湖、海（如有）分区，鱼类分常见、稀有、传说。受季节、天气、时间、鱼饵影响。

    ▪ 现代钓鱼：作为休闲小游戏，可解锁稀有鱼种图鉴，或用于现代餐厅。

    ▪ 用途：烹饪原料、送礼、完成订单、兑换稀有物品。

  ◦ 2.6.4 八大菜系烹饪系统：

    ▪ 体系：鲁、川、粤、苏、闽、浙、湘、徽八大菜系。每个菜系有数道代表性菜肴。

    ▪ 玩法：收集食谱、食材（来自种植、养殖、钓鱼、采集），在厨房制作。

    ▪ 效果：食用提供强力的临时BUFF（如精力恢复+50%持续一天）、赠送NPC大幅提升好感（尤其是对应籍贯的NPC）、完成节庆订单、在现代经营餐厅。

  ◦ 2.6.5 系统关联图：用文字或图示说明种植、非遗、钓鱼、烹饪、现代营生、NPC好感之间复杂的资源与任务网络。

3. 游戏进度

3.1 主线任务

1. 初入桃花谷 (0-7天)：学习基础，修复老屋

2. 重建家园 (8-30天)：解锁基础功能，结识村民

3. 节气考验 (31-60天)：经历首个完整季节周期

4. 古画之谜 (61-90天)：发现古画褪色真相

5. 宗族认可 (91-120天)：提升声望，获得村民信任

6. 最终抉择 (121-150天)：留下或离开，多重结局

9.差异化特色与市场壁垒

### 9.1 核心壁垒：双世界资源闭环
- **现实世界 (稀缺)**：竞品均为古代单世界。本项目独有的“现实文创店”提供了稀缺的现代叙事视角。
- **梦境切换**：借鉴竞品的经营玩法，但加入“梦醒”机制，增强代入感和紧迫感。

### 9.2 非遗深度 vs 竞品广度
- **竞品现状**：多为浅尝辄止的手工艺（如简单酿酒）。
- **本项目策略**：借鉴《Ancient Farm》的文明演进深度 ，将非遗作为产业链核心（造纸→书画修复），而非点缀。
