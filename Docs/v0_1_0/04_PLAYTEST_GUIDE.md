# v0.1.0 灰盒版 试玩指南

> 目标：验证「开垦 → 播种 → 浇水 → 生长 → 收获 → 出货换钱」核心循环的手感。

## 一、打开方式

1. 用 Unity 2022.3.57f1c1 打开项目（`Peach Blossom Valley`）。
2. 打开场景：`Assets/Scenes/01_FarmGreyBox.unity`。
3. 点击 Play。

> 场景丢失或需重建：菜单栏 `PBV → 构建灰盒场景 v0.1.0`（幂等，可随时重跑）。

## 二、操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 8 方向移动 |
| Space | 使用工具（上下文智能：空地→锄地 / 已耕→播种（有种子）或浇水 / 成熟→收获） |
| E | 交互（与 NPC 对话、往出货箱投货；对话中翻页） |
| Tab | 开关 24 格背包 |
| 1-0 | 选择快捷栏槽位 |
| F5 / F9 | 存档 / 读档 |
| N | 跳到次日（测试作物生长与结算） |

## 三、验证流程（约 5 分钟）

1. 走到自家门前空地，按 Space 锄地（地块变棕色）。
2. 再按 Space 播种（背包有 15 个萝卜种子，地块出现芽苗）。
3. 再按 Space 浇水（地块变深棕色）。
4. 按 N 跳到次日 → 芽苗长大一点（每天必须浇水才生长）。
5. 重复浇水 + N，第 3 天萝卜成熟（出现红色果实）。
6. 按 Space 收获 → 背包出现萝卜（Tab 查看）。
7. 走到西侧木箱，按 E 投入 → 控制台显示待结算金额。
8. 按 N 跨日 → HUD 金钱增加（+20/个萝卜）。
9. 找东侧「老农」按 E 对话，验证逐字显示与翻页。

## 四、已知限制（不是 bug）

- 美术全部为程序生成色块占位，无动画（Animator 参数已广播，等美术资源）。
- 无体力系统、无工具切换（智能上下文工具）、无商店购买。
- 只有 2 种作物（萝卜 3 天 / 白菜 4 天）。
- 存档在 `%USERPROFILE%\AppData\LocalLow\DefaultCompany\<项目名>\pbv_save.json`，删除即重置。
- 02:00 强制睡眠未实现（目前 24:00 自动跨日）。

## 五、反馈什么最有价值

- 移动/锄地/播种的**节奏与手感**（快慢、判定范围是否顺手）。
- 一天的时长是否合适（当前约 9 分钟）。
- 收获→出货→结算的反馈是否够清晰。
