# 谷中仙 v0.2.0 试玩指南

## 一、打开方式

1. 用 Unity 2022.3.57f1c1 打开项目（磁盘目录仍为 `Peach Blossom Valley`，产品名已正式改为《谷中仙》）。
2. 打开场景：`Assets/Scenes/01_FarmGreyBox.unity`。
3. 点击 Play。

> 场景丢失或需重建：菜单栏 `PBV → 构建灰盒场景 v0.1.0`（幂等，会生成全部 v0.2.0 资产：12作物/5材料/3NPC/商人/造纸台）。
> 存档异常/想重新开始：菜单栏 `PBV → 清除存档(开始新游戏)`。

## 二、操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 8 方向移动 |
| 鼠标左键 | 使用当前工具；成熟作物左键直接收获（无需切镰刀）；点在 UI 上不触发 |
| Space | 仅钓鱼 QTE 收竿（与农事彻底分离，不会误锄地） |
| Q | 切换工具（锄头→水壶→镰刀→种子→循环） |
| E | 交互（NPC对话/出货箱投货/商店购物/功能台；对话中翻页）／关闭由 E 打开的面板 |
| G | 送礼（靠近NPC时，送当前选中槽位物品） |
| F | 吃选中的料理（选中槽不是食物则自动找背包第一份） |
| Tab | 开关背包（24/36/48 格随扩容变化） |
| J | 开关任务日志 |
| L | 开关成就面板 |
| C / Esc | 开关制作界面 / 关闭 |
| K | 开关烹饪界面 |
| M | 开关矿洞界面 |
| U | 开关铁匠铺（工具升级） |
| P | 开关技能面板 |
| H | 帮助页（快捷键+玩法说明） |
| B | 建造台（房屋扩建）/ 关闭商店 |
| 1-0 | 选择快捷栏槽位 |
| F5 / F9 | 存档 / 读档 |
| N | 跳到次日 |

**地块高亮颜色**（玩家面向前方一格）：
- 黄 = 空地可锄 | 青 = 已耕地可种 | 蓝 = 需浇水 | 绿 = 可收获 | 暗红 = 不可耕种（绿地外）

## 四、经济闭环测试

1. 开局：¥500 + 萝卜/白菜/菠菜种子 + 树皮4 + 稻草4
2. 锄地→播种→浇水→跳日3次→收获萝卜 → 背包有萝卜
3. 萝卜投入出货箱→跳日 → 金钱+
4. 去商人买番茄种子（夏季作物）→ 金钱减少
5. 树皮x2→制浆→纸浆x2→抄纸→纸张x3→再做一批→纸张x6→制宣纸→宣纸x1
6. 宣纸投入出货箱→跳日 → +¥100
7. 给老农送萝卜 → 好感度提升
8. 任务自动追踪，完成自动发奖

## 五、已知限制

- 美术为程序生成色块占位
- 穿越时空不切换场景：灰盒只有一张农场地图，现代只改出货售价(×2)与 HUD/传送门状态，所有功能保持可用
- 体力0时不能工具但无晕倒机制
- 商店只支持购买，卖出走出货箱
- 季节切换仅HUD文字变化，草地不变色
- 对话固定无分支
- 无音效音乐
