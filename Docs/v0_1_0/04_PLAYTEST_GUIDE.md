# 谷中仙 试玩指南 · 6 个可玩循环

> **怎么读**：一条循环 = 从「投入」出发，绕一圈回到「投入」。按循环玩一遍就能覆盖主要功能，不必逐条打勾。
> 240 条逐条验收清单已归档到 `04_PLAYTEST_CHECKLIST.md`，只在排查具体功能时再翻。
> 功能覆盖至 v0.6.x；美术重绘与 NPC 剧情为下一里程碑。

---

## 开局 30 秒

1. Unity 2022.3.57f1c1 打开项目 → 场景 `Assets/Scenes/01_FarmGreyBox.unity` → Play
2. 想从头玩：`PBV → 清除存档(开始新游戏)`；场景异常：`PBV → 构建灰盒场景 v0.1.0`
3. 开局有：500 文、锄头/水壶/镰刀/斧头各 1、萝卜/白菜/菠菜种子、树皮 4、稻草 4

**地图**：所有交互点集中在北侧 8 排（每 4 格一个，头顶有「名称 E」名牌），中间与南侧是农田。

**只记 6 个键**

| 键 | 作用 |
|---|---|
| 左键 | 用当前选中格的物品（工具/种子/肥料/食物）；成熟作物直接收 |
| 1-0 | 选中快捷栏格子（格子上有数字角标，快捷栏上方显示「当前：XX · 用法」） |
| E | 交互 / 关闭面板（对着工坊按 E = 只看这台的制作配方） |
| N | 跳到次日（**所有循环都靠它推进**） |
| F | 吃选中的料理，回体力 |
| H | 游戏内完整帮助（全部快捷键与玩法） |

补充：`Q` 循环切工具 · `Tab` 背包（两界独立，标题会标哪边） · `C` 全部制作配方总览 · `K` 厨房 · `M` 矿洞 · `U` 铁匠铺 · `B` 建造台 · `G` 送礼 · `J` 任务 · `L` 成就 · `O` 声望订单 · `P` 技能 · `V` 人物面板 · **`R` 穿梭带货槽（每程 3 样，唯一跨境通道）** · **`X` 随时开驿站穿梭/兑换** · `Y` 图鉴 · `Space` 钓鱼收竿 · `F5/F9` 存读档 · `T` 从现代回谷 · `Esc` 关面板 · **`Shift+N` 推到 20:00 测打烊**

**地块高亮**：黄＝可锄 · 青＝可种 · 蓝＝要浇水 · 绿＝可收 · 暗红＝不可耕

## 循环一 · 种地 → 卖钱 → 再种（最基础，先跑通这条）

```
买种子 → 锄地 → 播种 → 浇水 → N 跳日 → 收获 ─┬─→ 商店 E 当场卖（06:00-18:00）─┐
                                              └─→ 出货箱 E（打烊/要倍率）→ N 结算 ─┤
                        ↺ 回到「买种子」←────────────── 拿到钱 ←──────────────────┘
```

- **两条卖货渠道，别混**：

| | 商店 E | 出货箱 E |
|---|---|---|
| 营业时间 | **06:00-18:00**，打烊后交易被拒 | 全天 |
| 结算 | **当场到账** | 次日 06:00 入账 |
| 价格 | 基础价 ×(1+好感溢价)，**不乘**节日×1.5 / 声望 | 可乘节日×1.5 / 声望，倍率在投入那一刻锁定 |
| 用途 | 急用钱、白天顺手卖；**现代唯一卖货渠道** | 谷内高价渠道、批量出货、打烊后唯一出路 |
| 在哪 | 两边都有（现代店用 ¥） | **只在桃花谷**，现代没有 |

- **背包里一切物品都能卖**（工具/种子/材料也行），每个物品直接定过价；`Tab` 打开背包 → 鼠标点格子选中 → 信息栏显示售价与「卖给本店」实收价
- **商店面板只列可买的东西**：卖货按 `Tab` 打开背包选中 → 回商店点「卖选中 ×1 / 卖选中整叠 / 全部卖出」。商店面板偏左、背包面板偏右，可同时看
- **商人好感 = 价格**：靠近商店按 `G` 送选中物品 → 买价最低 **8 折**、卖价最高 **+30%**；状态栏常驻显示营业状态 / 好感等级 / 买折扣 / 卖溢价
- **古今商店不通用，切世界整店隐藏**：

| 世界 | 店铺 | 币种 / 美术 | 可买的东西 |
|---|---|---|---|
| 桃花谷 | 杂货铺 / 酒楼 / 老农小摊 | 文 · 暖色 | 种子/食材/堆肥/工具/招牌菜 |
| 现代 | 现代杂货铺 / 古玩店 | ¥ · 冷蓝 / 金铜 | 现代资源/复合肥/图纸/工具；古玩店卖文物收藏品 |

- 测打烊：按 `Shift+N` 把时间推到 20:00（不换日）→ 商店交易被拒并提示「请投出货箱」→ 投货 → `N` 跳日结算
- 季节限定：每季 28 天，作物有季节，冬天种不下萝卜；雨天免浇水
- **节气加成**：HUD 右上角常驻小字 —— 雨水/谷雨浇水不耗体力、立春/立夏/立秋多长 1 天、芒种/秋分/寒露收获 +1
- **施肥**：选中堆肥或现代复合肥，左键点「已耕但没种子」的地块 → 收获 +1 或 ×3
- **代价**：现代肥收获后土地污染 3 天，须空置 N×3 祛毒才能再种；堆肥不污染
- 卡住自查：锄地高亮变青 → 播种出现幼苗 → 跳日逐阶段长大 → 绿色才能收

## 循环二 · 体力 → 野获 → 做饭 → 回体力

```
体力 → 挖矿 / 钓鱼 / 砍树 / 采集 / 采山 / 陷阱 → 食材·矿石 → 厨房 K 做菜 → F 吃 → ↺ 回到「体力」
```

- 矿洞可下潜 1~10 层（越深越稀有、越耗体力），概率遇怪打回合制（攻击/用药/逃跑，V 看血条）
- 矿石 → 铁匠铺 U 升工具 → 每次耗体力更少 → 能挖更深（这条支线接回循环一）
- **体力归零晕倒**送药婆，诊费 200 文；没钱就背债，下次有钱先还
- 生病：淋雨风寒 / 喝米酒醉酒 / 生肉腹泻 / 跌打 → 药庐做对应药，F 吃治好
- 睡床 E 体力回满；按 N 只回一半

## 循环三 · 原料 → 工坊 → 成品 → 出售（非遗产业链）

```
树皮/稻草/蓝草/陶土/药材/木材/矿 → 对应工坊 E 逐级制作 → 成品 → 出货箱/送礼 → ↺ 回到「采原料」
```

**10 个工坊各管各的配方**（按 E 只看本台；按 C 看全部总览，每条标注归属台）：

| 工坊 | 产业链 |
|---|---|
| 造纸台 | 树皮/稻草 → 纸浆 → 纸张 → 宣纸（100 文） |
| 染坊 | 蓝草 → 素布 → 纹样布 → 成衣 |
| 陶坊 | 陶土 → 陶坯 → 陶罐 / 青瓷盏 / 青花瓷瓶 |
| 药庐 | 药材 → 药墨 / 药酒 / 膏药 / 各类药与毒 |
| 木工坊 | 木材 → 木梁 / 家具 / **储物箱** |
| 磨坊 | 小麦→面粉、大豆→豆油、玉米→玉米油 |
| 酱园 | 大豆→酱油/陈醋；白菜/萝卜/黄瓜 + 盐 → **酱菜** |
| 茶坊 | 野茶 → 茶饼 / 茶饮 |
| 制糖坊 / 盐坊 | 甘蔗·甜菜→糖；盐石→盐 |
| 金银细工台 | 金矿→金锭，金锭+宝石→花丝珠宝 |

- 原料来自：杂货铺买、野地/林间采集、砍树、矿洞、自己种
- 糖/盐/油/酱 → 厨房做菜 → 接回循环二

## 循环四 · 养殖 → 蛋奶肉 → 菜与钱

```
买牲畜(畜栏 E) → 喂食 → N 跳日 → 收蛋/奶 → 连喂 2 天再屠宰(多 1 块肉)
     → 厨房做菜 / 酒楼 E 卖 → ↺ 回到「买牲畜」
```

- 鸡鸭牛羊猪共 5 种，不喂食跨日不产
- 蛋奶肉有对应菜谱；酒楼（大厨饱饱）可买卖蛋奶肉/调味料/招牌菜
- 老农小摊 E 买基础种子 + 堆肥，接回循环一

## 循环五 · 桃花谷 ↔ 现代 · 带货贸易

```
谷内攒货 → X 随时兑换(50 文 = ¥1) → R 装 3 样 → 传送门 E 穿梭(付通行费)
     → 实物进对岸背包 → 现代商店 ¥ 当场卖 / ¥ 买现代资源 → R 装 3 样 → T 回谷
     → 复合肥·图纸在谷内用 → ↺ 回到「谷内攒货」
```

- **两界背包独立**：Tab 标题标「桃花谷背包 / 现代背包」，物品**不会跟着穿越**。只有 `R` 槽的 3 样能跨境，且是**实物**进对岸背包，不再自动结算成钱，也没有文物 ×5 倍率
- **通行费**：出谷 50 文 / 回谷 ¥5，按出发世界币种扣；钱不够不让走（可先 `X` 兑换）
- **现代只剩 3 个交互点**：现代杂货铺、古玩店、传送门驿站。农田、10 工坊、厨房、矿洞、钓点、NPC、畜栏、床、**出货箱**全部隐藏；现代按左键不会锄地
- 现代杂货铺：活力饮料、能量胶、增产营养剂、现代复合肥、黑科技图纸、四件工具（F 研究图纸得 3 天增益）
- 古玩店：古陶罐 / 青铜古器 / 古玉佩 / 名家字画 / 古玉文玩 / 花丝珠宝 / 青瓷盏 / 青花瓷瓶 / 宣纸 / 药墨（¥ 买卖）
- **出货箱只在桃花谷**：现代没有出货箱，也没有「现代 ×2」。想高价卖就把货装 R 槽带回谷内投出货箱，或直接在现代商店当场卖
- 古董来自深矿；字画/文玩来自 NPC 好感 60 / 90 馈赠 → 接循环六
- `X` 随时打开时空驿站，两边都能双向兑换货币；穿梭本身不自动换汇
- **时间季节两边通用**（21 个跨日订阅方，独立时钟代价过高）：在现代期间谷内作物照常按 `N` 生长、次日出货照常结算
- **现代是独立场景**（`02_Modern.unity`，叠加加载，谷内场景不卸载）：场景里只有地面 + 两家店，美术可单独打开它作画。
  没生成该场景时自动退回旧逻辑，不影响可玩性；生成方式：菜单 `PBV → 生成现代场景 (02_Modern)`

## 循环六 · 送礼 → 好感 → 解锁与长线目标

```
产出物 G 送礼 → 好感升级 → 解锁药膳 / 亲密赠字画 / 挚友赠文玩
     → 现代高价卖 → 声望·订单·成就·图鉴 → 第 112 天结局
```

- 9 位 NPC 各有名牌、对话、作息（白天在建筑上班、晚上回家）
- `O` 看今日订单并交付 → 金钱 + 声望 + 菜品增益；`J` 任务自动追踪发奖；`L` 成就；`Y` 图鉴/鱼塘/彩蛋
- **建造与收纳**：砍树得木材 → 木工坊做储物箱 → 选中左键进入放置 → 再左键落地（房屋内外可放多个、每箱 36 格、E 打开可改名改色）；建造台 B 扩背包/体力上限/房屋装修格子

## 贯穿所有循环的「日循环」

按 `N` 跳一天，同时驱动：作物生长 · 天气晴阴雨 · 24 节气与加成 · 四季节日 · 每日随机事件 · 声望订单刷新 · NPC 作息 · 牲畜产蛋奶 · 污染祛毒 · 陷阱/笼箱收获 · 出货结算 · 体力减半恢复 · 增益倒计时 · 第 112 天结局。

> 一条最省事的完整路径：**循环一跑通 → 用卖的钱启动循环三 → 体力不够就走循环二 → 有余力开循环四/五/六**。

## 已知限制

- 美术为程序生成色块占位；无音效音乐
- NPC 对话固定无分支，好感只影响送礼/馈赠/解锁，剧情线（心事件）待下一里程碑
- 穿越时空不切换场景，但**只有时间季节、成就存档、货币通用**；农田/工坊/NPC/出货箱等仅谷内显示，现代只剩 2 家店 + 驿站
- 时间与季节两边共用一套时钟（完整独立需要 2 套时钟 + 2 套季节天气 + 重写 21 个跨日订阅方，代价过高，暂不做）
- 战斗为简化回合制面板（攻击/用药/逃跑），武艺招式与潜行/偷盗尚未实现
- 疾病仅覆盖风寒/醉酒/腹泻/跌打四类
