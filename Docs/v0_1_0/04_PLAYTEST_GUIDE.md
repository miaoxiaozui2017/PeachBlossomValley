# 桃花谷 v0.2.0 试玩指南

## 一、打开方式

1. 用 Unity 2022.3.57f1c1 打开项目（`Peach Blossom Valley`）。
2. 打开场景：`Assets/Scenes/01_FarmGreyBox.unity`。
3. 点击 Play。

> 场景丢失或需重建：菜单栏 `PBV → 构建灰盒场景 v0.1.0`（幂等，会生成全部 v0.2.0 资产：12作物/5材料/3NPC/商人/造纸台）。
> 存档异常/想重新开始：菜单栏 `PBV → 清除存档(开始新游戏)`。

## 二、操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 8 方向移动 |
| Space | 使用当前工具（按当前工具和地块状态执行） |
| Q | 切换工具（锄头→水壶→镰刀→种子→循环） |
| E | 交互（NPC对话/出货箱投货/商店购物/造纸台制作；对话中翻页） |
| G | 送礼（靠近NPC时，送当前选中槽位物品） |
| Tab | 开关 24 格背包 |
| J | 开关任务日志 |
| C / Esc | 开关制作界面 / 关闭 |
| K | 开关烹饪界面 |
| M | 开关矿洞界面 |
| U | 开关铁匠铺（工具升级） |
| B | 关闭商店 |
| 1-0 | 选择快捷栏槽位 |
| F5 / F9 | 存档 / 读档 |
| N | 跳到次日 |

**地块高亮颜色**（玩家面向前方一格）：
- 黄 = 空地可锄 | 青 = 已耕地可种 | 蓝 = 需浇水 | 绿 = 可收获 | 暗红 = 不可耕种（绿地外）

## 四、经济闭环测试

1. 开局：¥500 + 萝卜/白菜/菠菜种子 + 树皮4 + 稻草4
2. 锄地→播种→浇水→跳日3次→收获萝卜 → 背包有萝卜
3. 萝卜投入出货箱→跳日 → 金钱+
4. 去商人买番茄种子（夏季作物）→ 金钱减少
5. 树皮x2→制浆→纸浆x2→抄纸→纸张x3→再做一批→纸张x6→制宣纸→宣纸x1
6. 宣纸投入出货箱→跳日 → +¥100
7. 给老农送萝卜 → 好感度提升
8. 任务自动追踪，完成自动发奖

## 五、已知限制

- 美术为程序生成色块占位
- 体力0时不能工具但无晕倒机制
- 商店只支持购买，卖出走出货箱
- 季节切换仅HUD文字变化，草地不变色
- 对话固定无分支
- 无音效音乐
