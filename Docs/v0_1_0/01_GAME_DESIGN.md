# 0.1.0 游戏设计 (Game Design v0.1.0)

*(从 Docs/03_GAME_DESIGN_DOCUMENT.md 提炼，并根据 v0.1.0 风险评估优化)*

## 1. 核心世界观 (MVP)

*   **设定**：现代程序员梦中穿越到古代桃花谷。
*   **当前目标**：体验基础农耕循环，验证核心玩法。

## 2. 种植系统 (基础版)

### 2.1 基础循环
1.  **开垦**：使用锄头将荒地变为耕地。
2.  **播种**：在耕地上撒下种子。
3.  **浇水**：每天需浇水一次，保持土壤湿润。
4.  **收获**：作物成熟后使用镰刀或手收获。

### 2.2 操作优化 (手感)
*   **九宫格判定**：基于玩家面向，自动判定前方九宫格内最合适的地块。
*   **高亮反馈**：当前选中的地块必须有 **白色高亮边框**，明确操作对象。

### 2.3 作物 (首发 5 种)
*(从 20+ 种中精选用于测试)*
1.  **水稻** (春季)：基础粮食作物。
2.  **白菜** (春季)：快速生长，新手友好。
3.  **萝卜** (春季)：块根作物代表。
4.  **小麦** (秋季)：需加工测试 (如磨粉)。
5.  **油菜** (春季)：观赏性测试。

## 3. 物品与经济

### 3.1 背包与工具
*   **背包**：24格，支持堆叠。
*   **快捷栏**：8格，用于快速切换工具/物品。
*   **工具**：
    *   **锄头** (石制)：开垦。
    *   **水壶** (简易)：浇水。
    *   **镰刀** (石制)：收割/除草。
    *   **斧头** (石制)：砍树 (获取木材)。

### 3.2 基础经济闭环 (MVP新增)
*   **出货箱 (Shipping Bin)**：位于家门口。
    *   玩家将作物/物品投入箱中。
    *   每日清晨结算，将前一日投入物品的总价值转化为金钱。
    *   *目的*：形成“种植 -> 收获 -> 卖钱 -> 买种子”的最小循环。

## 4. NPC与交互 (基础版)

*   **首发 NPC**：**农夫老王** (新手引导者)。
*   **交互**：
    *   靠近按 `E` 键对话。
    *   基础对话流程 (问候 -> 引导 -> 告别)。

## 5. 时间系统 (昼夜循环)

### 5.1 时间流逝
*   **调整节奏**：`2现实秒 = 1游戏分` (一天 48 分钟)。
    *   *理由*：放缓节奏，给新手更多容错空间。
*   **昼夜变化**：
    *   06:00 日出
    *   18:00 日落
    *   光照颜色随时间变化 (清晨冷色 -> 正午暖色 -> 傍晚橘红 -> 深夜暗蓝)。

### 5.2 强制睡眠 (新增)
*   **逻辑**：
    *   到达 **02:00 (凌晨)** 若玩家仍未睡觉。
    *   **强制执行**：屏幕黑屏淡出 -> 传送回家中床上 -> 进入下一天 -> 06:00 醒来。
    *   *MVP暂无惩罚*：仅重置位置和时间。

## 6. 存档系统 (MVP)

*   **手动存档**：在床上睡觉时触发存档。
*   **数据**：保存玩家位置、背包物品、地块状态、时间、金钱。
