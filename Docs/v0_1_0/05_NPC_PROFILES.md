## 1. 老农（Lao Nong）

- **身份**：桃花谷老佃农，玩家落脚后的第一位引路人
- **年龄·外貌**：约 60 岁，佝偻微胖，皮肤黝黑，常戴破草帽，裤脚永远沾泥
- **所在**：北侧第 2 排
- **性格**：憨厚、话痨、刀子嘴豆腐心；对土地有近乎执拗的敬畏
- **背景**：守了这片谷三十年的老佃户，三年前东家举家迁城，田地荒芜。梦见"外人来耕"的预兆后应了玩家的出现，认定你是"命里该来的人"。
- **喜好礼物**：① 自种萝卜/白菜（"自己种的最香"）② 家常菜（清蒸鱼等，怀念老伴手艺）③ 石锄/好农具（实用至上）
- **讨厌礼物**：① 宝石/金锭（"这玩意儿不能吃"）② 现代饮料（"瓶瓶怪水"）
- **口头禅**："地不会骗人，你待它好，它就待你好。"
- **声线基调**：沙哑粗粝的老年男声，语速慢，爱叹气
- **关联系统**：农耕引导（开局教学）、订单常客（餐厅订单顾客之一）
- **好感里程碑钩子**：亲密——讲出东家离开的往事与"谷中会再热闹起来"的心愿；挚友——把祖传《耕织图》残卷相托，暗示古画线索
- **美术方向**：草帽+麻布短褂+泥靴；主色土黄/草绿；标志性道具：肩扛木锄。单线粗笔，圆胖轮廓。
- **[待确认]** 老农与"谷中仙"古画彩蛋的关联强度（目前仅口头暗示）。

## 2. 药婆（Yao Po）

- **身份**：隐居桃花谷的游方女医，采药制药为生
- **年龄·外貌**：约 50 岁，银发挽髻，面有细纹但眼神清亮，随身药篓
- **所在**：北侧第 2 排（药庐）
- **性格**：外冷内热，毒舌但医者仁心；厌弃虚礼
- **背景**：曾是太医院医官，因谏言获罪流落民间，择谷而居。识得百草，也懂"药墨""药酒"古法，是谷中非遗药脉的守艺人。**早年为采疫区药，常年夜行山路、翻墙入村，练就一身轻身暗行的本事**——哪味药能迷、哪味能解，她比谁都清楚。
- **喜好礼物**：① 草药（薄荷/甘草/灵芝，越稀有越欢喜）② 药酒（自酿或换来）③ 蓝草（入药亦入染，识货）
- **讨厌礼物**：① 现代能量胶/饮料（"化学汤"）② 宝石（"不能救命"）
- **口头禅**："身子是革命的本钱——哎，说溜了，是活命的本钱。"
- **声线基调**：中年至老年女声，平澹带冷幽默，偶尔哼药谣
- **关联系统**：药墨·药酒产业链、体力/恢复料理；**拓展职能：潜行/偷盗教学**（"听风辨位" → 药庐暗格 → 追回失窃文物支线）
- **好感里程碑钩子**：亲密——赠你一册手绘《桃花谷本草》，并授"听风辨位"的潜行入门；挚友——透露太医旧事，嘱"古画上的药方，或许真能救人"，并带你夜探古玩黑市、追回被盗文物
- **美术方向**：素灰布裙+深蓝比甲+银发髻；主色青灰/药绿；标志性道具：竹编药篓、小药铡。单线，清瘦轮廓。
- **[待确认]** 药婆兼任"潜行/偷盗"导师是否合适（原方案是独立神偷·叶飘；现按"不新增 NPC"并入）。若你更想让这份"隐世高手"气质落在别人身上（比如守卷道人），我随时可移。

## 3. 书生（Shu Sheng）

- **身份**：落魄画师兼私塾先生，谷中书香一脉
- **年龄·外貌**：约 30 岁，清瘦，长衫洗得发白，指节有墨痕
- **所在**：北侧第 2 排
- **性格**：迂腐可爱、自尊心强、内心自卑；醉心书画，不通农事
- **背景**：原是城中画师，因一幅"犯禁"的桃花图被逐，避居谷中设帐授徒（徒仅老农之孙）。痴迷文房四宝与制墨古法，是"名家字画"馈赠最合理的出处。
- **喜好礼物**：① 宣纸/纸张（视为珍宝）② 墨锭/笔（文房同好）③ 兰花（君子之喻）
- **讨厌礼物**：① 酒肉（"俗") ② 工具农具（"此物违我")
- **口头禅**："笔墨虽小，可载山河。"
- **声线基调**：青年男声偏文弱，咬字清晰，念白腔
- **关联系统**：文房/制墨产业链、书画（字画馈赠核心来源）
- **好感里程碑钩子**：亲密——为你画一幅《桃花谷初雪》相赠（即名家字画文本出处）；挚友——道出那幅"犯禁桃花图"与穿越古画的隐秘关联
- **美术方向**：月白长衫+褪色青巾+墨痕指尖；主色月白/墨黑；标志性道具：卷起的画轴、狼毫笔。单线，瘦长书卷气。
- **[待确认]** 书生与"谷中仙"古画是否为同一幅画的不同线索（建议是，串联主线）。

## 4. 商人（Shang Ren）

- **身份**：走南闯北的行商，杂货铺掌柜
- **年龄·外貌**：约 55 岁，圆脸富态，一双精明小眼，算盘不离手
- **所在**：北侧第 1 排（杂货铺）
- **性格**：精明和善、见利不忘义；消息灵通，是谷中"八卦中心"
- **背景**：年轻时跑过大码头，见过大世面，今在谷口开了间杂货铺，卖种子也收山货。对"现代来的稀奇物件"格外上心，是玩家倒卖套利的最佳伙伴。
- **喜好礼物**：① 金锭/宝石（硬通货）② 高价山货（古董/文玩）③ 稀奇的现代小物（好奇）
- **讨厌礼物**：① 一文不值的杂草石块 ② 过期料理
- **口头禅**："生意人，讲的是个'值'字。"
- **声线基调**：老年男声，圆滑热络，算盘声常伴
- **关联系统**：杂货铺（买卖）、跨时空贸易/穿梭结算（RMB 与现实物价线）
- **好感里程碑钩子**：亲密——给你"内部价"与贸易情报；挚友——引荐城里古玩行，坐实文物高价变现
- **美术方向**：赭红绸衫+方巾+算盘；主色赭红/金；标志性道具：手中算盘、钱袋。单线，富态圆轮廓。
- **[待确认]** 商人是否兼营"现代店铺"（文创铺）的剧情接口（为现实世界线铺垫）。

## 5. 阿蓝（A Lan）— 染织坊主人

- **身份**：染织手艺传人，染织坊主人（草木扎染 + 纺织，蓝草染布后自行织造，染织一条龙）
- **年龄·外貌**：约 22 岁，利落短发（或双丫髻），双手常年靛蓝，笑起来有虎牙
- **所在**：北侧第 3 排（染织坊旁）
- **性格**：爽朗爱笑、手巧、有点小固执；对蓝草与纹样有执念
- **背景**：祖辈以蓝草扎染为业，她是谷里最年轻的守艺人。把"蓝草染布→扎纹→缝衣"做成一条非遗小产业链，成衣既卖钱也讨好感。
- **喜好礼物**：① 蓝草（原料刚需）② 素布/成衣（同行欣赏）③ 河鲜（溪钓所得，近水而居）
- **讨厌礼物**：① 暗沉脏污之物 ② 现代化学染料（"毁我靛蓝")
- **口头禅**："一缸靛蓝，能染半生欢喜。"
- **声线基调**：青年女声，清亮明快，带笑意
- **关联系统**：染织产业链（蓝草染布 → 织造 → 扎纹成衣）、河/湖钓点（近水）
- **好感里程碑钩子**：亲密——赠你一方亲手扎染的帕子；挚友——传你"双面异色纹"秘技，并盼你把现代审美带进老花样
- **美术方向**：靛蓝围裙+白袄+蓝染头巾；主色靛蓝/月白；标志性道具：染缸、扎染方巾、织机。单线，利落短打。
- **[待确认]** 阿蓝与"现代高产资源/设计"的互动台词（她应是对"现代审美"最感兴趣的 NPC）。

## 6. 柳娘（Liu Niang）— 铁匠娘子

- **身份**：铁匠铺当家的女铁匠——父亲是前镖局总镖头，家学两样：打铁与拳脚
- **年龄·外貌**：约 28 岁，高马尾，臂有锻痕，嗓门大，腰间皮围裙；抡锤时肩背绷成一张弓
- **所在**：北侧第 3 排（铁匠铺主人，工具升级相关）
- **性格**：豪爽直率、外冷内热、护短；力大但心细
- **背景**：承父业执锤，谷中农具兵器皆出其手。表面凶，实则最疼晚辈。玩家工具升级（锄/斧/水壶/镰）的对话与折扣可经她之手。**父亲走南闯北护镖半生，一身功夫只传了她七八成**——谷里没人知道，那个挥锤的女人能徒手撂倒三个壮汉。
- **喜好礼物**：① 铜矿/铁矿/金锭（原料与硬通货）② 火属性/烈酒（助兴）③ 精铁成品
- **讨厌礼物**：① 易碎瓷器（"啪一声心疼") ② 娇弱花草
- **口头禅**："好铁要千锤，好人要打磨。"
- **声线基调**：青年女声，洪亮爽利，带金属质感的笑
- **关联系统**：铁匠铺（工具升级 U）、矿洞产出消纳；**拓展职能：武艺/打怪教学**（"趟子手"基本功 → 野外战斗 → 护谷剧情）
- **好感里程碑钩子**：亲密——送你一柄私打的小锄（工具外观彩蛋），并传你"趟子手"基本功、解锁基础战斗；挚友——为你重淬"家传陨铁"，并授"断山镖"心法，开启精英怪/秘境与护谷剧情
- **美术方向**：深褐皮围裙+灰布束袖+高马尾；主色铁灰/炭黑；标志性道具：铁锤、火星。单线，英气轮廓。
- **[待确认]** 柳娘同时兼任铁匠铺(U)面板背后的 NPC 与武艺导师（原方案是独立"前镖头·秦九"；现按"不新增 NPC"并入，用"镖头之女"承接家学）。这个双重身份你认不认？

## 7. 守卷道人（Shou Juan Dao Ren）

- **身份**：守卷人，古画与道藏的看护者
- **年龄·外貌**：看不出年纪，灰袍广袖，拂尘在手，眼神淡漠如水
- **所在**：北侧第 3 排
- **性格**：神秘、淡然、惜字如金；似早知玩家来历
- **背景**：守着谷中祠堂里一卷"会显影的桃花古画"与一柜道藏。他与"谷中仙"隐藏彩蛋（见闻≥20/声望≥200/成就≥4 触发）直接相连，是穿越真相的钥匙人物。
- **喜好礼物**：① 古籍/宣纸/墨（同道）② 古玉（通灵之物）③ 静心之物（兰花/茶）
- **讨厌礼物**：① 喧嚣俗物（现代电子声）② 血腥猎获
- **口头禅**："卷中自有乾坤，你且自看。"
- **声线基调**：中年男声，空远无波，似含回响
- **关联系统**：古画彩蛋（谷中仙）、隐藏结局线索、文房/古籍
- **好感里程碑钩子**：亲密——允你近观古画一瞬；挚友——吐露"画中人非画，是归来者"的真相，接通主线结局
- **美术方向**：灰蓝道袍+广袖+拂尘；主色玄灰/月白；标志性道具：拂尘、卷轴。单线，飘逸疏朗。
- **[待确认]** 守卷道人是否即"谷中仙"本尊或引路人（建议为引路人，留白给真相）。

## 8. 老窑（Lao Yao）— 陶工

- **身份**：制陶（瓷）老匠人，窑口主人
- **年龄·外貌**：约 65 岁，满脸窑火熏痕，手指粗粝，笑时眯眼
- **所在**：北侧第 3 排
- **性格**：沉稳寡言、慢工出细活；以器物观人
- **背景**：守着一座老龙窑，烧得一手青瓷。是谷中"陶瓷"非遗的活化石，也是未来可扩展的制陶/瓷产业链（陶土→陶胚→瓷瓶）的天然主人。
- **喜好礼物**：① 陶土/高岭土（原料）② 瓷成品/古瓷（同好）③ 火候好物
- **讨厌礼物**：① 粗制滥造的破物 ② 易碎却无价值的赝品
- **口头禅**："土经火，方成器；人经事，方成人。"
- **声线基调**：老年男声，低缓温吞，像窑火噼啪
- **关联系统**：陶瓷产业链（潜在扩展）、矿石/窑火、古玉文玩（挚友馈赠可作"古瓷文玩"）
- **好感里程碑钩子**：亲密——赠你一只手作青瓷盏；挚友——传你"冰裂开片"绝技，并说古瓷里也封着一段谷中旧事
- **美术方向**：赭黄窑服+半褂+熏痕脸；主色赭黄/青瓷绿；标志性道具：陶轮、青瓷瓶。单线，敦实轮廓。
- **[待确认]** 是否把"制陶/瓷"做成第 4 条非遗产业链（与造纸/扎染/金银细工并列），还是仅剧情与馈赠。
