# 谷中仙 试玩指南（功能覆盖至 v0.6.x · 美术重绘与 NPC 剧情为下一里程碑）

## 一、打开方式

1. 用 Unity 2022.3.57f1c1 打开项目（磁盘目录仍为 `Peach Blossom Valley`，产品名已正式改为《谷中仙》）。
2. 打开场景：`Assets/Scenes/01_FarmGreyBox.unity`。
3. 点击 Play。

> 场景丢失或需重建：菜单栏 `PBV → 构建灰盒场景 v0.1.0`（幂等，会生成全部 v0.2.0 资产：12作物/5材料/3NPC/商人/造纸台）。
> 存档异常/想重新开始：菜单栏 `PBV → 清除存档(开始新游戏)`。

> **测试期布局**：所有交互点集中在地图**北侧四排**，每 4 格一个，头顶挂「名字 + 快捷键」标签（运行时自动重排，不用重建场景）。
> 第1排 y=9：出货箱 / 杂货铺 / 造纸台 / 厨房 / 溪钓点 / 矿洞 / 铁匠铺
> 第2排 y=6：床 / 建造台 / 传送门 / 灵兽祠 / 老农 / 药婆 / 书生
> 第3排 y=3：染坊 / 河钓点 / 湖钓点 / 阿蓝 / 柳娘 / 守卷道人 / 老窑
> 第4排 y=0：金银细工台 / 陶坊 / 药庐 / 木工坊 / 野地采集 / 林间采集
> 第5排 y=-3：采山入口 / 布陷阱 / 衣柜
> 中间与南侧留给农田。地形/地图生成本阶段不动；第3、4、5排由运行时自动补建，无需重建场景。

## 二、操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 8 方向移动 |
| 鼠标左键 | 使用当前工具；成熟作物左键直接收获（无需切镰刀）；点在 UI 上不触发 |
| Space | 仅钓鱼 QTE 收竿（与农事彻底分离，不会误锄地） |
| Q | 切换工具（锄头→水壶→镰刀→斧头→循环）；工具/种子/肥料/食物等物品选中后左键直接使用 |
| E | 交互（NPC对话/出货箱投货/商店购物/功能台；对话中翻页）／关闭由 E 打开的面板 |
| G | 送礼（靠近NPC时，送当前选中槽位物品） |
| F | 吃选中的料理（选中槽不是食物则自动找背包第一份） |
| Tab | 开关背包（24/36/48 格随扩容变化） |
| J | 开关任务日志 |
| L | 开关成就面板 |
| C / Esc | 开关制作界面 / 关闭 |
| K | 开关烹饪界面 |
| M | 开关矿洞界面 |
| U | 开关铁匠铺（工具升级） |
| P | 开关技能面板 |
| V | 开关人物属性面板（时日/荷包/状态/技艺/非遗/好感） |
| H | 帮助页（快捷键+玩法说明） |
| B | 建造台（房屋扩建）/ 关闭商店 |
| 1-0 | 选择快捷栏槽位 |
| F5 / F9 | 存档 / 读档 |
| N | 跳到次日 |

**地块高亮颜色**（玩家面向前方一格）：
- 黄 = 空地可锄 | 青 = 已耕地可种 | 蓝 = 需浇水 | 绿 = 可收获 | 暗红 = 不可耕种（绿地外）
